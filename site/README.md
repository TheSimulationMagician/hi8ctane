# The live site (version 1)

What goes live at hi8ctane.com: the 2.7 website and app screens, exactly as designed, plus the new partner page for schools and rental shops. GitHub Pages publishes this folder on every change on main (`.github/workflows/pages.yml`).

- `index.html` opens the web page on a computer and the phone site on a phone.
- `B27-*.dc.html` are the 2.7 screens from the canvas, run by `support.js` (the same player as in `design/`). The launch kit is left out: it's for us, not for riders.
- Changed from the canvas 2.7 page: the web page has a FOR SCHOOLS link in the top bar, a "For schools + rental shops" band above the closing section and a footer link; the phone landing has the same card and footer link.
- `B27-Schools.dc.html` is the partner page: what schools and rental shops get, how it works, and a short form that opens an email to hello@hi8ctane.com with the details filled in.
- Sample data throughout, except the partner email: nothing riders tap or type is saved.

The same changes are on the design canvas as the page "2.7.1 · live site: schools + rental shops".
